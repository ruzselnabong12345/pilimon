Yotpo Product Retriever & Updater Extension Setup

Follow the instructions below to create and install your custom Chrome extension for retrieving and updating Yotpo product metadata.

Step 1: Create local folder

Create a new folder on your computer (e.g., yotpo-updater-extension).

Step 2: Create required extension files

Inside that folder, create the following 3 files using Notepad or a text editor:

1. manifest.json

Step 3: Load the Extension in Google Chrome

  1. Open Google Chrome (or any Chromium browser like Edge/Brave).
  2. In the address bar, navigate to: chrome://extensions/
  3. In the top-right corner of the Extensions page, turn on Developer mode.
  4. In the top-left corner, click the Load unpacked button.
  5. Select the folder you created in Step 1 (containing manifest.json, popup.html, and popup.js).
  6. The extension "Yotpo Product Retriever & Updater" will now appear in your extensions bar! Click its icon to launch the tool anytime.
